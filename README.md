# Word Ladder

> NeetCode 150 · Graphs · Blind 75 — BFS on an implicit graph: neighbors are generated by mutating one letter at a time (26·L tries) and checked against the dictionary set. Go, stdlib only, tested.

## Problem

Shortest chain from one word to another, each step changing exactly one letter and landing on a dictionary word. Return the chain's word count, 0 when impossible (including when the target isn't in the dictionary at all).

## Approach

Unweighted shortest path = BFS; the twist is the graph is never built. Comparing all word pairs is O(n²·L); instead, generate each word's neighbors directly — try all 26 letters at each of L positions and keep the ones in the dictionary set, O(26·L) per word. **Deleting** words from the set the moment they're enqueued does double duty as the visited set and keeps later levels faster. Level-order counting (a whole queue generation per step, as in Rotten Oranges dsa-088) gives the chain length. The named upgrade for huge dictionaries is bidirectional BFS — expand the smaller frontier from both ends.

**Complexity:** O(n · 26 · L) time, O(n) space.
